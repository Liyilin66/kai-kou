# 任务：手机端核心练习流程可用

- 日期：2026-10-07
- 分支：`lyl`（完成审查后合并 `main`）
- 关联：`docs/improvement-plan.md` 第 3 节（RA 录音诊断）、第 8 节（用户试用）

## 背景

2026-10-07 部署 `ac1b2cd` 后，手机上无法完成 RA 练习：练习页是固定三栏布局，右侧录音区被挤出屏幕。

代码证据：

- `src/views/RAView.vue`：`.practice-body` 为 `grid-template-columns: 276px minmax(620px,1fr) 292px` 且 `overflow: hidden`，最小约 1190px 宽；只有 `max-width:1320px` 和 `min-width:1600px` 两个断点，没有手机断点。
- `src/views/RAResultView.vue`、`RAListView.vue`、`WFDView.vue`、`WFDListView.vue`：同样只有 1280px 以上的断点。
- `HomeView.vue`、`ProfileView.vue`、`AgentView.vue` 已有 640–760px 断点。

## 目标

**手机上能完整走通 RA 的核心流程**：登录 → 首页 → RA 入口 → 练习（准备、录音、提交）→ 结果页。目标是"可用、不出错"，不是重新设计手机版视觉。

为什么现在做：第一轮评测要用手机录样本；第 4 阶段的真实用户试用，用户大概率用手机。

## 范围

| 优先级 | 页面 | 要求 |
|---|---|---|
| P0 | `RAView.vue` 练习页 | 必须完整可用 |
| P0 | `RAResultView.vue` 结果页 | 可读、可返回、可重练即可。**不要做精细适配**：第一轮第 2 阶段会重写这个页面，新版本将按手机优先设计 |
| P1 | `RAHomeView.vue`、`RAListView.vue` | 能选题、能进入练习 |
| P1 | `AuthView.vue`、`HomeView.vue` | 检查一遍，有问题才改 |
| 不做 | WFD、DI、RTS、WE、RS、RL、私教、个人中心 | 本次不改，后续单独排 |

## 做法要求

1. **只新增手机断点，不动桌面样式。** 在各页面现有 `<style>` 末尾新增 `@media (max-width: 767px)` 块；≥768px 的渲染必须与现在一致。
2. **练习页三栏改单栏**，手机上的顺序：
   1. 顶部栏、步骤条（步骤条可横向滚动或压缩为"第 x / 4 步"）
   2. 状态横幅 + 倒计时
   3. 朗读原文
   4. **录音 / 提交按钮**（必须在不滚动太多的位置可见，触控区域不小于 44×44px）
   5. 题目信息、朗读提示、我的战绩、AI 建议、历史记录（放到下方，可折叠的保持折叠）
3. **解除固定高度和内部滚动**：手机上 `.practice-body` 等容器改为自然高度、页面整体滚动，避免出现"区域内滚动 + 页面滚动"两层嵌套。
4. **不改任何逻辑**：录音、计时、提交、评分、存储相关的 JS 一行不改。若必须调整模板结构（例如调整 DOM 顺序），优先用 CSS `order` 实现；确需改模板的，在交付说明里列出原因。
5. 不新增依赖，不引入新的 CSS 框架。

## 验收标准

在浏览器响应式模拟和至少一台真机上：

1. 视口 375×812 和 390×844 下，P0、P1 页面**没有横向滚动条**，文字不被截断到无法阅读。
2. 真机（iPhone）完整做一次 RA：准备 → 录音 → 提交 → 看到结果页，全程不需要缩放页面。
3. 1440×900 和 1920×1080 下，修改前后截图对比，桌面布局没有变化。
4. `npm run build` 通过，`npm test` 通过。
5. diff 只涉及上表 P0 / P1 页面的样式（及必要的少量模板顺序调整）。
