# 任务 15：DI / RTS / RL 发音改为"本版本未评估"

- 日期：2026-10-09
- 分支：`lyl`（改线上代码，**Claude 审查后才能合并 `main`**）
- 背景：任务 14 未达门槛（稳定性 71.4% < 80%），DI 内容自动判定不上线。按事先约定只做一致性修改：RA、RS 已显示"发音：本版本未评估"，DI、RTS、RL 仍在显示 LLM 根据文字猜出的发音分，口径不一致。

## 要做的

1. **结果页**（DI、RTS、RL）：发音一项不再显示数字，改为"本版本未评估"，附一句原因（与 RA/RS 相同文案）。
2. **总分**：不再计入发音。用剩余评分项按原有权重**等比例重新归一**后得到 10–90 总分；在 `docs/ra-scoring-rules.md`（或现用的规则页）中写明这三个题型的现行计分方式，以及"内容、流利度仍由 LLM 根据识别文字判断，是已知局限"。
3. **写库**：新记录的 `score_json.scores.pronunciation` 存 `null`，并带 `score_version`（如 `di-legacy-np-0.1`、`rts-legacy-np-0.1`、`rl-legacy-np-0.1`）。旧记录不回填，读取时不受影响。
4. **读取方兼容**：首页、历史、个人中心、私教中，`pronunciation: null` 不显示为 0，也不计入发音平均值（复用 RA/RS 已有的处理）。
5. **README**：在"局限与下一步"中补一句：DI / RTS / RL 仍为"识别文字 + LLM"评分，发音不评；DI 内容判定已做离线验证但未达门槛（链接任务 14 文档）。

## 不做

- 不新增依赖、不改表结构。
