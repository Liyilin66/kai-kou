# 任务 17：全站练习页视觉统一 + DI 入口一致性

- 日期：2026-10-10
- 分支：`lyl`（改线上页面，**Claude 审查后才能合并 `main`**）
- 前置：任务 16 已有共享外框 `SpeakingPracticeShell.vue` 与色板 `speaking-practice.css`

## 问题

1. **配色割裂**：首页、RA、RS、WFD、个人中心是暖棕色系（`#7C5C3E`、`#FAF6EF` 等），RTS 整个模块（首页、列表、练习、结果、模板库、收藏）是深蓝色系（`#1B3A6B`、`#E8EDF5`），练习页还有亮绿主按钮和橙色"下一题"按钮。用户从首页点进 RTS 像换了一个网站。其他页面（WE、RL、DI、私教 `AgentView`）配色未逐一核实。
2. **DI 入口是死的**：生产环境 `VITE_ENABLE_DI` 关闭，路由守卫把 `/di` 重定向回首页，但首页仍显示 DI 卡片（点了没反应），AI 私教横幅写死"建议优先练习 ×× 和 DI"，本周目标里也有"DI 0/2"。产品在推荐一个用不了的功能。

## 要做的

### A. 先盘点（不改代码）

在 1440 和 375 宽度下逐页截图：首页、练习中心、题库、学习计划、学习报告、个人中心、AI 私教，以及 RA / RS / WFD / RTS / WE / RL 各自的列表、练习、结果页。列一张表：页面 → 当前色系 → 是否偏离暖棕标准。截图放本机 `output/task17/`，不进 Git。

### B. 统一视觉

1. **标准**：以 `speaking-practice.css` 的色板和 RA 练习页为准（顶栏、步骤条、卡片圆角/边框、主按钮）。不引入新风格。
2. 把共享色板提到全站可用的位置（如 `src/styles/` 下的全局变量），偏离标准的页面改用这些变量；能复用 `SpeakingPracticeShell.vue` 的口语练习页（RTS、RL）就复用。
3. 按钮层级统一：每屏一个主按钮（深棕实心），次要操作用描边按钮。RTS 练习页的亮绿"正在准备播放"和橙色"下一题"改为这套层级。
4. 标注色、状态色（正确绿、错误红、提示橙）保留语义，但用色板里的同一组变量。
5. 题型的辅助色（首页卡片顶部色条）可以保留，作为区分，不作为页面主色。

### C. DI 入口一致性（`VITE_ENABLE_DI` 关闭时）

1. 首页（`HomeView.vue`、`HomeReplicaView.vue`、`HomeDesktopDashboard.vue`）的题型卡片、搜索、目标进度、热力图、弱项中都不出现 DI。
2. 私教横幅和建议文案（`src/lib/home-desktop-dashboard.js`、`HomeView.vue` 第 105 行和第 575 行附近，以及其他写死的地方）不推荐 DI；推荐只从已开放的题型中选。
3. 用一个公共函数给出"已开放题型列表"，各处都从这里取，不要在每个文件里各写一次过滤。
4. 开关打开时行为与现在相同。

### D. 去掉"假的"和"死的"（原则：做减法，不补新页面）

1. **侧边栏**：`HomeView.vue` 第 473–478 行、`HomeDesktopDashboard.vue` 第 71–76 行。"练习中心 / 学习计划 / 学习报告 / 题库"只是跳到首页锚点（`/home#quick` 等），实际点击无反应。改为：能稳定滚动到首页对应区块的就修好滚动并高亮当前项；首页上没有对应区块的就删掉该项。**不为它们新建页面。**
2. **写死的假数据**：首页 AI 私教卡片的两条消息和时间戳"10:32 / 10:33"（`HomeView.vue` 第 978 行附近、`src/lib/home-desktop-dashboard.js` 第 42–46、710 行附近）、"最近练习"的占位记录（`HomeDesktopDashboard.vue` 第 36–38 行，含不存在的 72/90、64/90 分数）。有真实数据就显示真实数据；没有就显示空状态（如"还没有练习记录，先做一道 RA"），不显示看起来像真实记录的样例。
3. **名不副实的入口**："PTE 备考资料包 · 免费领取"实际跳到 WE 模板库。改成如实的文案（如"WE 模板库"），或删除。
4. 盘点（A）时一并记录：所有点了没反应、跳错页面、显示样例数据的按钮和卡片，按上面的原则处理，并在交付说明里列出处理结果。

### E. 手机与桌面适配

1. 盘点（A）时同时记录 375 宽度下错乱的页面（横向滚动、遮挡、溢出、按钮挤压、字太小）。
2. 修复方式：在现有页面上补响应式样式，复用 RA/RS 已做好的手机布局写法；**不重写页面结构，不改组件逻辑**。
3. 标准：375、768、1440 三个宽度下无横向滚动、无遮挡，主按钮在手机上可直接点到。
