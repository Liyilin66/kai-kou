## 计分规则（ra-score-0.1）

全部为纯函数、确定性计算：同一条诊断结果永远得到同一个分数。**不调用任何模型。**

### 1. 内容（官方规则 + 项目判定）

官方（Score Guide p.15）：每一处 replacement、omission、insertion 计 1 个错误。

- `N` = 参考原文词数（对齐后的参考记号数）。
- `errors` = 替换 + 漏读 + 插入（含重复读出的多余词）。
- 项目判定（必须写进规则页，标明"项目判定"）：
  - `homophone`、`low_confidence` 不计错误（识别无法区分）；
  - 填充词（um / uh 等）不计错误（官方未对 RA 说明）；
  - 同一参考位置的替换与漏读只计 1 次。
- `content_ratio = max(0, N - errors) / N`。
- 展示："内容：正确 x / N 词（k 处错误）"。

### 2. 流利度（官方 0–5 分档 + 项目阈值）

官方分档描述见 Score Guide p.46（规则页已整理）。官方没有给秒级阈值，以下阈值是**项目自定**，写入规则页：

- `D` = 犹豫次数（句中停顿 ≥ 0.5 秒，沿用现有诊断）+ 识别到的重复次数
- `L` = 长停顿次数（≥ 2.0 秒，沿用现有诊断）
- `W` = 语速（词 / 分钟）
- `R` = 最长连续片段：相邻词之间都没有 ≥ 0.5 秒停顿的最长词数

| 档位 | 官方档名 | 判定（按顺序取第一个满足的） |
|---|---|---|
| 0 | Disfluent | `L ≥ 2` 且 `R < 3`；或 `W < 40` |
| 1 | Limited | `L ≥ 2`；或 `D ≥ 6` |
| 2 | Intermediate | `L = 1`；或 `D` 为 4–5 |
| 3 | Good | `D` 为 2–3 |
| 4 | Advanced | `D = 1`；或 `D = 0` 且 `W < 90` |
| 5 | Highly proficient | `D = 0`、`L = 0`、`W ≥ 90` |

展示："流利度：3 / 5（Good）"，并列出决定档位的证据（如"2 次犹豫"），点击可回听。
已知局限写进规则页：假开头无法检测；重复依赖识别结果，可能漏检。

### 3. 发音

显示"**本版本未评估**"，附一句原因："现有技术无法可靠测量发音，测不出来的项不给分。"可链接到规则页的说明。**不计入总分，不给任何数字。**

### 4. 总分 10–90（项目自定换算）

```
total = round(10 + 80 × (0.5 × content_ratio + 0.5 × fluency_band / 5))
```

规则页写明：官方未公开单题合成与 10–90 换算；本分数由内容与流利度两项按上式换算，不包含发音，不等于 Pearson 官方单题分。

## 要做的

1. **`backend/speech/scoring.js`**（纯函数）：`scoreRA({ alignment, pauses, metrics })` → `{ score_version: 'ra-score-0.1', content: { correct, total, errors, ratio }, fluency: { band, label, evidence: { D, L, W, R } }, pronunciation: { status: 'not_assessed' }, total }`。
2. **接入诊断流程**：`analyze-service.js` 在生成证据后计算分数；分数写入 `speech_analyses`（放在 `metrics.score` 下即可，**不需要改表结构**）以及 `practice_logs.score_json`：`scores: { overall: total, content: round(10 + 80 × ratio), fluency: round(10 + 80 × band / 5), pronunciation: null }`，并带 `score_version`。
3. **回填脚本** `scripts/backfill-ra-scores.js`：对已有的 `status = 'done'` 诊断记录，用已存的对齐和停顿数据重算分数，并更新对应练习记录。默认只打印将要修改的内容（dry-run），加 `--apply` 才写入。
4. **兼容读取方**：首页、RA 历史、个人中心、私教读取 `scores.overall` 时，新记录恢复显示分数；`pronunciation: null` 不得显示为 0 或 NaN，也不能被算进发音平均值。
5. **结果页**：顶部大号总分（10–90）；三张评分卡：内容（x/N 词）、流利度（n/5 + 官方档名）、发音（本版本未评估）。总分旁边放"评分规则"入口，打开应用内页面或弹窗，内容来自 `docs/ra-scoring-rules.md` 的要点（官方规则、项目判定、未评估说明）。手机 375 宽度可用。
